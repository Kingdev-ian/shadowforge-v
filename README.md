# ⚡ ShadowForge

AI-powered gamified learning platform for university students.

## What is ShadowForge?

ShadowForge makes university studying feel like a game.
Students earn XP, unlock topics, climb leaderboards, and
master their subjects through story-driven content, clean
exam notes, and interactive quizzes.

## Launch Subjects

- Microeconomics
- Statistics
- Financial Accounting
- Business Law
- Organizational Behavior

## Tech Stack

- HTML, CSS, JavaScript (Frontend)
- React (UI Framework)
- Node.js + Supabase (Backend)
- Claude AI (Content Generation)
